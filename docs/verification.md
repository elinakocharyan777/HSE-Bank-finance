# Проверка HSEBank.Finance

Дата: 3 октября 2026 года. Проверена версия из основной ветки Dz-KPO, подпапка kpo-dz2. Исходный код при переносе не изменён.

## Условия

Сборка и запуск в официальном контейнере .NET SDK 8.0 на ноутбуке. Выполнено `dotnet build HSEBank.Finance.sln -c Release`: 0 предупреждений, 0 ошибок. Сценарии выполнялись через фактическое консольное меню в отдельных запусках программы.

| Сценарий | Результат |
|---|---|
| Счёт 0, доход 100, расход 30 | Баланс 70 |
| Аналитика за январь 2025 | Доход 100, расход 30, итог 70 |
| Расход 30 при балансе 0 через меню | Отказ, баланс 0 |
| Импорт examples/operations.csv | 2 операции, баланс 70 |
| Импорт examples/operations.json | 2 операции, баланс 70 |
| Начальный баланс 100, затем пересчёт без операций | Ошибка: баланс стал 0 |
| Доход 100, затем редактирование суммы на 0 | Ошибка проверки показана, но баланс стал 0 |
| Экспорт CSV, затем импорт этого файла | Импортировано 0 операций |
| Экспорт JSON, затем импорт этого файла | Импортировано 0 операций |

## Причины ошибок и приоритеты

1. **Высокий приоритет: изменение баланса при неуспешном редактировании.** `OperationFacade.UpdateOperation` сначала меняет баланс, затем вызывает `Operation.Edit`, который отклоняет нулевую сумму. Проверку и подготовку нового состояния нужно выполнять до изменения сущностей.
2. **Высокий приоритет: потеря начального баланса.** `BalanceService.RecalculateAccountBalance` суммирует только операции. Начальный баланс нужно хранить отдельно или представлять начальной операцией с согласованными правилами аналитики.
3. **Средний приоритет: несовместимость форматов.** CSV-экспорт добавляет первым столбцом id, а импорт ожидает type. JSON-экспорт выдаёт CategoryName, а импорт ожидает Category. Нужен общий контракт и тест экспорт → импорт.
4. **Единая проверка операций.** Проверка недостатка средств есть в MenuActions, но отсутствует в OperationFacade/BankAccount. Импорт вызывает фасад напрямую. Перенести инварианты в слой логики.

Эти замечания не исправлялись в рамках выделения репозитория. Проверка не является полным аудитом всех методов и граничных случаев.
